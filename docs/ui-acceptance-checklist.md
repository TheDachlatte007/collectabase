# UI Acceptance Checklist

Use this checklist after visual changes to Collectabase. Test with a populated collection as well as an empty one.

## 360px mobile

- Bottom navigation and Add button remain reachable above the safe-area inset.
- Search, filters, and forms fit in one column without page-level horizontal scrolling.
- Long titles, platform labels, and action rows wrap or truncate without overlapping controls.
- Lots use compact records rather than requiring table-width scrolling.

## 768px tablet

- Collection filters remain readable and primary actions stay visible.
- Price Browser keeps its filter controls available while its data table scrolls intentionally.
- Settings backup, restore, and appearance controls remain usable without clipped buttons.

## 1440px desktop

- Sidebar, main content, and data-dense views have clear surface boundaries.
- Keyboard focus is visible for navigation, buttons, inputs, and menus.
- Theme and density changes preserve readable text and controls of at least 36px in compact mode.
